ASCII2BIN

This tool converts an ASCII file to a binary file which can be
read in by the VITESS modules. 

This tool can be used by users who have computed a part of an
instrument by using their own codes and wish to continue with VITESS.

The format of the ASCII file has to be as described in the help document
of module writeout.
