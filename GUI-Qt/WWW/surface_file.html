VITESS Tool Generate Surface Files

This tool generates surface files that are used in the module 'bender'. The following parameters have to be given.

  

Parameter
 Description
 Values and range
Number N of channels
 The bender can consist of N channels, each of which consists of M wafers.
The wafers of a channel must have the same length, the channels may have different lenghts and a spacing at the exit (see below).
In case of equal lengths and no spacing, there is no difference between L channels a 1 wafer and 1 channel a N wafers.
 >= 1
Number M of  wafers
per channel 
 Each channel consist of M identical wafers.
 >= 1
Thickness of wafer
[cm]
 Layer thickness of each wafer
 > 0
Radius of the bender
[cm]
 Radius of the middle of the bender. The radius for each wafer is calculated in a way that they all form parts of circles with one common centre.
 >= 0
0 = straight
Space between channels at exit
[cm]
 The channels may be separated by a certain distance at the exit. The distance is supposed to be zero at the entrance and increases linearly over the bender length.
 >= 0
0 = no space between       channels at exit
File name
 Path and name of the file into which the data shall be written.
If no path is given, the file will be written to the directory .../Vitess.
