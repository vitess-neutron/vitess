VITESS Module Resonator Drabkin


This module simulates a system which was called "Drabkin resonator". The main field is a periodical magnetic field with permanent amplitude or with some amplitude distribution. The amplitude distribution should has a gauss or sinus law. This is gives a possibilities to improve the peak of neutrons, which was flipped. The permanent magnetic field should be added to the periodic magnetic field. This field must be situated in the perpendicular plane relativly the periodical magnetic field. Such field is calling "guide magnetic field". If we apply these two fields, we must got a flipper, which is working in the narrow wavelength range. The full width on the half height is depending from number of periods of the periodical magnetic field. Also let me remind, incoming neutron beam should contain a some range of wavelength. No monohromator should be installed before resonator!
The random magnetic field can be added also.
The axis OX has the direction of neutron flight.
The spin precessions are treated classically i.e. this module only rotates the spin vectors belonging to trajectories which pass through the rectangular geometry.
No attenuation is considered during the flight.
