VITESS Options

Some options, to be set from the Options menu in the GUI main window, modify the GUI appearance and execution details.

You may Save settings to a gui file, to be loaded later by Load settings.

Some options on fonts and sizes take effect after Apply settings only, because all Tk windows have to be redrawn for this purpose.

Fonts

GUI elements use font settings for (family, size, type) triples. You may change these to your preferences and click Apply Settings.
In some cases where font defaults are to small or big, you may just click Smaller fonts or Bigger fonts to have an effect immediately.

Check Mode

Before a given pipe is executed, or when you click on the "Check" button, VITESS checks entries for syntactic correctness,
and bails out if some parameters for instance have values outside the specified range.

A special problem arises when you load instrument definitions of older VITESS versions, where some new parameters have been added since.
Mostly these are selection parameters, where new options have been added, and the default is that one which was constant before.

In strict mode this is an error, in normal mode no value is provided in the pipe for that parameter, and in mode set_default this value is explicitly set.

Save Instr. Mode

When saving an intstrument settings done in a session for series are normally not saved, but you may enable this with the mode with series.

Output compression

If you save the output of the last pipe module to a file, this file may be reduced in size when you enable compression.

The smallest size comes with float+gzip compression, you may use nodebug in any case where you need no debug information on individual trajectories.
A better compression comes with float mode, where the position information is reduced to float accuracy.

Execution Mode

If you re-do a simulation and want to see what changes with a new version or some parameter modification, the save old execution mode might be of interest.

The mode copy results helps to store results of simulations in special subdirectories.

Buffersize

Modules write buffers of neutrons down the pipe. For computers with enough memory, and especially when using helper threads,
you may speed up execution if you increase the default value of 10000 neutron trajectories per buffer.

Plot mode

You may select dots + lines instead of default dots only.

Trajectories

You may select the output format of geometry information to X3D (default), SVG xy, SVG yz, or plain text.

Browse selection

MAC OS X: File selction in an Aqua browser window allows to select files of a given extension only.
Trouble comes when you want to plot a file with a non-default file extension. Select option all here to enable selection of any file.

Helper applications

You may select another plot program to be used instead of gnuplot here.
If you have a virtual reality tool to render X3D scenes installed, you may select it here, default is InstantPlayer.

XControl options

Color

You may change colors of GUI elements to your preferences.

Info Level

If you chose expert mode, select a module afterwards, and click on text labels of parameters, you will see more information on parameters, for instance restrictions.

Timeout

If a simulation might take too long, and you want to restrict the execution time, you might select a timeout period in seconds. After that period a simulation will be ended, like when you click the Stop button.

Recovery Snapshots

VITESS automatically writes snapshots of the GUI state, to be recovered when some changes are to be undone. Your may set the number of snapshots kept, and the time interval shapshots are written.
