VITESS Module Writeout

The writeout module can be inserted between two VITESS modules or at the end of a pipe to convert  binary neutron data (the output of the antecendent module)  to an ASCII file of nine columns containing the following useful information about each neutron:

1. the ID of the trajectory. e.g. AA0000914

2. the tracing information (T: tracing, N: no tracing)

3. the 'color' of the trajectory (reserved for the user's demands)

4. total neutron time (whole history of the neutron is considered) in ms

5. neutron wave length in Å

6. neutron probability = neutron current [n/s] represented by the trajectory (whole "probability history" is considered)

7.-9. the exact neutron position (x- ,y- ,z- coordinate, [cm]) with respect to the coordinate system provided by the module which generated the binary output  read by writeout

10.-12. neutron flight direction (x- ,y- ,z- coordinate of the direction cosinus)

13.-15. the spin components (x- ,y- ,z- coordinate of the spin)

There is currently one exception to this scheme: The neutron data file taken from the output of the detector module differs with respect to  columns 7.-9  (as described in the detector help section).
 

Note: The writeout module does not disturb the normal processing of the pipe!
