Standard Deviation

Calculates the standard deviation from XY data.
The output is written to the monitor and into a file given by the user. 
This file can be later used as input for a visualisation program. For a new set of data one needs to give a new output file name.

First the average value  is calculated then: SD^2 = < x^2 - ^2 > .
