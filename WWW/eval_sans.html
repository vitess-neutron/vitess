VITESS Module SANS-Evaluation


The module eval_sans delivers the function S(Q) or F(Q) of a SANS simulation. This has to be done in two steps: In a first run, an isotropic scatterer is used; then the simulation with the real sample is started. The use of the isotropic scatterer is necessary to eliminate influences of the intensity distribution from moderator und instrument. In addition to the module eval_sans, a module eval_elast is needed, using the 'evaluation parameter' 'momentum transfer'. This will deliver the reference spectrum. Therefore, both modules need identical binning of the Q-axis.
The procedure is like that: Assuming the SANS instrument is finished (including sample, detector, eval_elast and eval_sans), you change the parameter 'scattering object' in the parameter file to 'isotropic scattering'. (You might save this as an instrument of its own.) Now you start this simulation. The output 'spectra file' of eval_elast now contains the reference spectrum obtained by an isotropic scatterer. It needs to be copied and renamed to assure that it will not be changed by the following simulation(s). This file is now the 'reference file' in the eval_sans module. This module will calculate I(Q) of the sample and deliver S(Q) as the ratio

      S(Q) = F_norm * I_smpl(Q)/I_ref(Q)

F_norm considers the different scattering probabilities of the SANS samples and the isotropic scatterer into forward direction (θ=0). It is of the order of magnitude 1E-4 to 1E-3 and can either be determined by adjusting the low Q end to S(Q)=1 or ....
