VITESS Module Monitor

Monitor

The module monitor is needed to obtain information about the wavelength, time, divergence or position (y-z-plane) dependent intensity or polarization distribution of the neutron output given from the previous module.
It writes the probability counts or average polarization according to the segmentation of the interval of interest to the monitor file. The third column represents the standard deviations per channel. The data of this file can be visualised by appropriate means, e.g. 'Origin', or one can try to use the plot facilities of the VITESS GUI. The monitor module does not influence the neutron stream between the neighbouring modules, unless the option exclusive counts is activated (see below).

The following information has to be given as an input

monitor file name

number of bins: the interval to be considered (e.g. the wavelength range)
                          will be partitioned into number of bins segments of equal size.
                          In the case of position, one can give a different number of bins for
                          each direction of the y-z-plane for obtaining a rectangular segmentation.

colour:               if colour is zero, the intensity of all trajectories is displayed
                         if colour is 1, 2, ....., only the trajectories with that colour are taken into account

normalise with binsize: if activated, in each channel count-rate and standard deviation are normalised with the binsize on the wavelength, time-of-flight, etc axis.

minimal value, maximal value: the values defining the interval of interest.

probability weight: if one deactivates the probability weight each neutron
                          is considered with the weight 1, otherwise (default) the attributed
                          probabilities (due to the operations of the modules before) are considered.

exclusive counts: if activated, only those neutrons which have been monitored
                          successfully (e.g. the wavelength of the neutron lies in the monitored
                          wavelength interval) are transferred to the subsequent module.
begin, end of evaluation: (for 1-dim case, not used in 'monitor_time')
                          only neutrons arriving in that time interval are considered in the
                          evaluation

If monitoring polarization

analysis direction: in case of monitoring polarization distributions it is
                          represented by a vector in cartesian coordinates
