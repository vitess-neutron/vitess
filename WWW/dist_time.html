VITESS Tool Distance-Time Plot

This tool shall help to check and visualize the designed chopper system. It is written independently of other parts of the package and can therefore be seen as a cross-check to ChopperPhases etc.. It generates a ps-file containing a distance-time-plot. The file is written to the parameter directory, if it is known. The frame is defined by the chopper with the greatest distance to the source. The other choppers are supposed to be frame overlap choppers.
