Vitess Tutorials

This page contains exercises that illustrate the usage and special features of different VITESS modules. Some exercises are taken from the joint Vitess/McStas workshop that took place in Berlin 18.-20.09.2013; the respective McStas examples can be found at http://2013.essworkshop.org/. These exercises are based on VITESS 3.1. Input files are given in the subdirectories, as well as .pdf files containing detailed description of the exercises as well as (some) solutions.

Beginner Example

The BeginnerExample folder contains an introduction to VITESS simulations and basic usage of the most common modules. It is divided in two parts:

  • Ex1: Source, sample, and detector modules.
  • Ex2: Guide and chopper modules.

Useful material that can be found in the same folder:

  • ESSpowder_common.pdf describes the instrument setup to be simulated.
  • ESSpowder_VITESS.pdf contains instructions on how to implement this in VITESS.
  • Solutions in GUI files for both Ex1 and Ex2 are provided.

Detector Example

In this exercise we want to see how different kinds of neutron detectors can be modeled in VITESS. We concentrate on artificial setups showing the detector performance.

  • Ex3: Detection material and efficiency, resolution effects, tube geometry, detector array, event mode output file.

Guide Example

In the GuideExample directory, different types of guides are considered and their differences are compared.

  • Ex4: Straight, curved, kinked, ballistic, and elliptic guides.

Ray-tracing Example

In this exercise, we assume we have optimized a guide system using m=6 mirror coating. Now we want to find out where in the guide we can use a lower coating without losing flux on the sample. We don’t want to use a high coating to reflect a lot of neutrons that get lost somewhere else in the system, or contribute to background! Therefore, we use raytracing to select the neutrons we want, and then choose the coating appropriate to transport them.

  • Ex5: Use neutron raytracing to determine supermirror coating (m-value) necessary in different guide sections.

Samples

In this exercise folder we study in more detail the sample modules in Vitess, both for diffraction and reflection.

  • Ex6: Reconstruct powder samples, get the background from sample environment, create a sample for reflectometry and study the differences between considering or not the incoherent scattering.

Super-mirror Systems Example

Finally, the SupermirrorSystems folder contains an exercise to model complex systems of supermirrors using the sm_ensemble module. In this module, any user-defined coordinates and orientation of supermirror plates can be given. You will build a bi-spectral beam extraction system consisting of several, differently inclined mirrors surrounded by guide walls.

  • Ex7: Build a bi-spectral beam extraction system consisting of several mirrors inserted partly into a guide.
