VITESS Module Runtime


The module runtime counts the time it is running in its position in the pipe. It does not alter any neutron. Once the pipe is finished, i.e. the simulation is done until the pipe position of the runtime module the needed time is added to the log output.

Parameters for module 'runtime'

None.
