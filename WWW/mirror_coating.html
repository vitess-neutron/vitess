VITESS Tool Generate Mirror Files

This tool generates reflectivity files that are used in the modules 'guide' and 'bender'. The parameters m, R_0, R_m, Q_c (cf. Figure) and the file name have to be given. If no path is given, the file will be written to the directory .../Vitess/Modules.

          ^
          |
 R_0  |_____________
          |                         . \
          |                         .   \
          |                         .     \
          |                         .       \
 R_m ....................................\
          |                         .          |
          |                         .          |
          |                         .          |
          |                         .          |
         +----------------+------+-----> Q, theta
        0                      Q_c     m*Q_c(Ni)
                             theta_c   m*theta_c(Ni)

m          :  factor of supermirror
Q_c      :  crit. momentum transfer  (see figure)
theta_c :  crit. angle for lambda = 1 Angstroem
R_0      :  reflectivity for 0 <= Q <= Q_c
                  (or 0 <= theta <= theta_c)
R_m     :  reflectivity for Q = m * Q_c(Ni)
