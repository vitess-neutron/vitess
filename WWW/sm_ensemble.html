VITESS Supermirror-Ensemble

This module simulates an ensemble of up to 50 mirror planes. This can be used for the simulation of more complicated optical systems, with branch geometry. For example one can use 4 elements as a normal guide and put one transparent element into this, tilted by an angle relative to the main (beam) axis and use it as polarizer. Both sides of the supermirror planes reflect.
Shapes and positions of the SM elements have to be given in the file "geometry and reflectivity data". Size and shape of each element are defíned by giving the four corners in a plane perpendicular to the beam. The center of each mirror is then moved to his final position; then two rotations are executed to get the mirror in the right orientation. A triangular shape can also be treated: 3 'corners' have to be co-linear for that.

The algorithm calculates the angle of inclination for each trajectory and decides about reflection or transmission depending on the reflectivity curve. There are 2 formats to give the reflectivity data:
In the old file format, 3 parameters have to be given for spin-up and spin-down neutrons separately: theta_c, theta_csm and R_csm (see examples below). For angles below theta_c, a reflectivity of 1 is assumed, for angles above thetaCSM, reflectivity of 0 is used. For angles between theta_c and thetaCSM, the reflectivity decreases linearly from 1 to R.
In the new file format, only the m value is given (for spin-up and spin-down neutrons). The module then calculates the reflectivity according to an empirical model assuming also a linear decrease between theta_c and theta_csm, but an S-shaped drop to zero after theta_csm. It describes the reflectivity curves of state-of-the-art coatings based on data delivered by the producers in 2019.
Furthermore, transmission can be excluded by setting the number in the first column to 2, while in the old format requires a high value of μ*d for that. Instead of μ*d and μincoh*d, the thickness d of the mirror is used assuming the material given on the main window of the module.
See also the 2nd and 3rd table for details of the two file formats.

Visualisation of neutron paths or collision points is available. The module will visualize only the first 10000 trajectories or points.

New format

The new format makes use of the available empirical description of the mirror reflectivities valid for mirror coatings produced by Swiss Neutronics. Apart from geometrical information, in this format only the thickness d and the m-number for spin-up and spin-down neutrons has to be given. This format can only be used if sapphire or silicon is chosen as mirror subtrate!

Example 1: Polarizing V Cavity

A V type cavity is a transmission polarization device, by which a wide neutron band with large divergence can be polarized. Here it is realized as a single V cavity using an FeSi supermirror, which shows total reflectivity up to m=1 and zero reflectivity above m=4 for spin-up and total reflectivity up to m=0.6 and zero reflectivity above m=0.7 for spin-down neutrons (cf. figure and table).
In the old format, 5 numbers have to be given to define the reflectivity curve (s. Table below), both for up- and down-neutrons. In the new format, it is done by just giving the m-value.

Example 2: Extraction System

The following example shows the realization of a bi-spectral extraction system consisting of 3 vertical m=3 supermirrors and 2 horizontal m=2 supermirrors. Two of the vertical mirrors are 0.77° inclined (relative to the beamline) in the direction shown in the figure, the other one is not. All have the same length of 6.47 m. (The example was somewhat simplified after the sketch was made.)
Note that apart from the second mirror, the mirrors do not transmit neutrons.
