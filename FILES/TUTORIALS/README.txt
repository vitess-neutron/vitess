FILES/TUTORIALS contains exercises that illustrate the usage and special features of different VITESS modules. Some exercises are taken from the joint Vitess/McStas workshop that took place in Berlin 18.-20.09.2013; the respective McStas examples can be found at http://2013.essworkshop.org/. These exercises are based on VITESS 3.1. Input files are given in the subdirectories, as well as .pdf files containing detailed description of the exercises as well as (some) solutions.

- BeginnerExample
  An introduction to VITESS simulations and basic usage of the most common modules, in two parts: 
  (Ex1) source, sample and detector
  (Ex2) guide and chopper 
  ESSpowder_common.pdf describes the instrument setup to be simulated, ESSpowder_VITESS.pdf contains instructions on how to implement this in VITESS

- DetectorExample
  Detection material and efficiency, resolution effects, tube geometry, detector array, event mode output file

- GuideExample
  Straight, curved, kinked, ballistic and elliptic guides

- RaytracingExample
  Use neutron raytracing to determine supermirror coating (m-value) necessary in different guide sections

- Samples
  Reconstruct powder sample, background from sample environment, reflectometer sample w/o incoherent scattering

- SupermirrorSystems
  Build a bi-spectral beam extraction system consisting of several mirrors inserted partly into a guide
