README

This program has been developed on Unix and Windows, 
and runs fine on both operating systems.

Installation under Unix

1. check
--------
Your operating system should be Linux (versions from 2.0.35).
Vitess may be compiled from sources for other versions of Unix. 

We assume Tcl/Tk software with a version 8.2 or higher
is installed separately. If you miss information, try
http://www.scriptics.com/software/
VITESS may use BLTwish extensions to Tcl/TK for plots of monitor modules.
Tcl/TK Versions >= 8.5 are not compatible with BLT, but VITESS works fine
with these versions where simpler plot widgets replace BLT widgets automatically.

The VITESS software comes to you as a gzipped tar file.
When your browser asks for a file name to store the tar file,
it might suggest
	vitess_download
without any .tar.gz extension. We assume you change that default
to a name with .tar.gz ending like vitess.tar.gz .

You may compare the CRC32 or MD5 checksums of the downloaded
vitess.tar.gz with those stated at
https://www.helmholtz-berlin.de/vitess

The file vitess.tar.gz might be de-tared in whatever
<vitess parent directory> you want, like /usr/bin for root installation
or $HOME for personal installation.

Silver Bullet
-------------
If you have perl installed on your system, fetch the script installAndTest

	cd <vitess parent directory>
        installAndTest -v vitess.tar.gz

This will check your Tcl/Tk installation, extract the tarball,
check for shared libraries, ...
        installAndTest -h
to see what is possible.

Or:

2. do
-----
	cd <vitess parent directory>
	gtar zxvf vitess.tar.gz

	(if you do not have gtar, try
		gunzip vitess.tar.gz
		tar xvf vitess.tar
	)	

3. edit script
--------------
Please change the first line of the vitess start script
	<vitess parent directory>/vitess/Vitess
from
	#!/usr/local/bin/bltwish
to the correct path of the bltwish image.
If you do not have a bltwish installed, just take the normal wish.
We used vitess with different versions of wish and bltwish, but
recommend the latest versions 8.4 / 2.4.

(Due to a bug in /usr/local/lib/tk8.4/tkfbox.tcl browsing
directories and files fails with some distributions. 
We send you a patch on request, or you may produce the patched file by 
       installAndTest -p tkfbox.tcl
)

If you want to install Vitess for others, you might adopt the
perl script callVitess to your needs.


4. try it
---------
	<vitess parent directory>/vitess/Vitess

Alternatively you may the script callVitess provided in the tarball.

Missing shared libraries?
-------------------------
installAndTest may find shared libraries needed e.g. for the
bender or visual executable. Those libraries may be missing on minimal 
systems, but are easily installed from RPMs by your local Unix guru.

Compilation from sources
------------------------
The Tcl/Tk code should work with little or no modification
for all Unix derivates.

C sources have been compiled for Linux, elder versions for
Solaris and Tru64, too.

Difference to the Windows version
---------------------------------
The Windows version comes alongside with standard Tcl/Tk
software. For the Vitess part the only difference to the
Unix version is to be seen in the directory for executable
images. The MODULES directory contains those files, you
need the right ones for your operating system. 
For module guide (from guide.c) we find

guide.exe		 Windows 32 bit
guide_Linux		 Linux i386
guide_Linux_x86_64       Linux x86 64 bit architecture
and in the past
guide_SunOS		 Solaris sparc
guide_OSF		 Tru64 alpha
